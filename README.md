This is for my Hack Club Fallen project. I'm turning my PS3 Super Slim into a mini desktop retro arcade.




# Project Name: The PS3 Arcade

## Project Overview
I am building a compact, 1-player desktop arcade machine powered by an intact, software-modded PlayStation 3 Super Slim(PS3 HEN) running RetroArch. The goal of this project is to hopefully get to visit China(I hope). Anyway its also to learn 3D modeling and wiring, as well as just make my childhood PS3 way better since I love it so much! All this stuff I've never done before so I'm excited to learn.

## Key Hardware Components
* **Brain:** Modded PS3 Super Slim running PS3HEN and RetroArch.
* **Display:** Upcycled Apple iPad LCD screen (utilizing an external HDMI-to-iPad LCD controller driver board to maintain a native retro 4:3 aspect ratio).
* **Controls:** Plug-and-play Zero Delay USB Arcade encoder kit with mechanical arcade buttons and a joystick.
* **Chassis:** A fully custom, modular 3D-printed interlocking shell designed to snap/bolt together without requiring too many tools to assemble.

## What I Aim to Learn During Fallen
1. How to design structural, interlocking modular panels in CAD (Onshape) that fit on a standard 3D printer bed.
2. How to convert a raw tablet display panel into a functioning HDMI monitor.
3. How to manage airflow and thermodynamics to keep an enclosed console cool using 5V USB fans.
